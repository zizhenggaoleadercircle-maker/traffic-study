# dep

Pinned or listed Python dependencies. This project’s canonical dependency list is **[pyproject.toml](../pyproject.toml)**.

- **Editable install (recommended):** from the repo root, `pip install -e .`
- **Requirements file only:** `pip install -r dep/requirements.txt`

The repo root **[requirements.txt](../requirements.txt)** forwards to `dep/requirements.txt` for backward compatibility.
